# Autonomous Software Engineer Agent

An AI-powered agent that can write code, fix bugs, run scripts, install packages, and commit to Git — all by itself.

Built with **Groq (Llama 3.3 70B)** 

---

## What it can do

-  Write Python files and run them
-  Fix its own bugs automatically (self-healing)
-  Install any Python package
-  Read and write files
-  Commit code to Git
-  Handle multi-step tasks autonomously
-  Log every action to session.log
